# 과거 데이터와 예정 공모 잔여 작업 점검

## 실행 범위

2026-09-30 현재 저장된 과거 데이터와 2026-09-29에 수집한 공식 DART 원문을 재검증했다. 오늘의 정정·철회 여부를 새로 조회한 결과가 아니며 전체 시장 완전성도 보장하지 않는다. 모델 학습·성능평가·배포는 수행하지 않았다.

## 완료한 수정

1. 예정 문서의 정정 전·후 표가 함께 있는 경우 명시적인 정정 후 구역만 선택한다. 정정 후 표가 여러 개이거나 구역이 불명확하면 보류한다. 선택한 구역 제목, 주석 번호, 표·행 위치와 원시값을 보존한다.
2. 실제 문서의 대괄호 정정 표제, 기명식 보통주 표기, 요일·공백 포함 날짜와 같은 해의 축약 종료일을 처리한다. 역전된 날짜는 승인하지 않는다.
3. 예측 단계 학습 진입점에서 실제 prediction_at, 해당 시각의 근거, 수요예측 결과 공개 시각과 근거, 피처별 공개 시각을 함께 요구한다. 상장 전 공개됐다는 이유만으로 수요예측 전/후 학습을 승인하지 않는다. 날짜만 있는 공개 자료는 보수적으로 다음 날부터 사용하며 같은 날의 수요예측 전 시점은 승인하지 않는다.
4. 시간 감사 원장의 값이 전부 결측으로 표시된 경우 실제 값이 있는 피처를 승인하던 조기 반환을 제거했다. 중복 증거, 공개 시각 불명, 예측 이후 공개는 차단한다.
5. 기존 학습표본 감사 스크립트가 과거 날짜와 '2026년 평가 미사용' 문구를 다시 생성하던 부분을 수정했다. 이미 소진한 최종 평가 이력은 유지한다.

## 실제 원문 재검증

- 과거 ZIP 표본: 20220808000054, 20210111000425 두 건 모두 통과. 인증 API를 새로 호출한 것이 아니라 저장 원문 재검증이다.

- 예정 53개 후보의 일정 승인: 21건에서 31건으로 증가했다. 정정 후 구역으로 추가 처리된 10건에는 멜콘·네오사피엔스·브릴스와 스팩 등이 포함된다.
- 멜콘은 정정 후 모집가액 표의 12,300원을 원시값으로 보존했다. 본 일정 원장은 가격 자동 승인기가 아니므로 final_offering_price는 계속 NULL이며 모델 승인도 0건이다.
- 나머지 22건: 일반공모 보통주 범위 밖 14건, 표 구조 부재/모호성 4건, 계보·원문 추가 확인 4건. 범위 밖을 누락 IPO라고 간주하지 않으며, 보류가 해결됐다고 보고하지 않는다.
